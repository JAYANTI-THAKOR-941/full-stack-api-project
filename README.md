# Full Stack API Project

Client-server product storefront with cart, login, registration and product administration interfaces.

## Project structure

- `client/src/pages/`
- `client/src/admin/ProductManagement.jsx`
- `client/src/services/api.js`
- `server/controllers/`
- `server/models/`
- `server/routes/`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/full-stack-api-project.git
cd full-stack-api-project
```

Install dependencies in `client` and `server` separately. Configure the database and API endpoint; start the server using its package scripts, then run `npm run dev` in `client`.
